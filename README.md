# 🎵 Conversor de YouTube para MP3

Um aplicativo web simples e rápido construído com Node.js para baixar e converter vídeos do YouTube em arquivos de áudio MP3 na qualidade de 128kbps.

## 🚀 Tecnologias Utilizadas

* **Node.js** & **Express** (Para o servidor web)
* **ytdl-core** (Para extrair o áudio do YouTube)
* **fluent-ffmpeg** (Para converter a mídia para MP3)
* **HTML/CSS/JS** (Para a interface do usuário)
